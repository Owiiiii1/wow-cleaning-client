# WOW NOW CLEANING — Brand Notes

Extracted from `Wow Now BrandBook_s (4).pdf` for Flutter development.

## Colors

| Name | Hex | Role |
|------|-----|------|
| Picton Blue | `#37B7FF` | Primary blue (logo, accents) |
| Yellow | `#FFDF59` | Accent |
| Dark Liver | `#4D4D4D` | Dark text / icons |
| Background | `#F7FBFF` | Soft app fill |

Code: `lib/theme/app_theme.dart` → `AppColors`

## Typography

- **Montserrat** only
- Bold / SemiBold → headlines, preferably uppercase
- Regular / Medium → body / subheads
- Code: `AppFonts` + `google_fonts`

## Logo / wordmark

- Full: WOW NOW CLEANING
- Short UI wordmark: **WOW NOW**
- Font: Montserrat Bold
- Color: Picton Blue `#37B7FF`

## Mascot

- **Benjamin** — toy poodle in a suit (brand manager character)
- Asset: `asset/benjamin.png`
- Used as circular avatar in app header (not client photo)

## Incorrect use (from brand book)

- Do not use non-corporate colors
- Do not distort logo proportions
- Keep clear space around logo
